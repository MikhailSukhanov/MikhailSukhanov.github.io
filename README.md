# My Personal Portfolio & Utilities

A multifunctional personal website built with a focus on clean code, modular architecture, and modern React practices. This project serves as both a professional portfolio and a playground for web utilities.

[**Live Demo**](https://mikhailsukhanov.github.io)

## 🌟 Key Features

* **Mini-Apps Integration**: Includes built-in tools like a **Notepad** and a **Calculator**.
* **Internationalization**: Full support for English and Russian languages with a seamless toggle.
* **Dynamic Theming**: Support for both Dark and Light modes with a seamless toggle to suit user preference.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MikhailSukhanov/MikhailSukhanov.github.io.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```

## 🧪 Testing

I prioritize reliability. The testing suite focuses on user behavior rather than implementation details.

To run the tests:
```bash
npm test
```

## 🛠 Tech Stack

* **Core**: React 19 (TypeScript)
* **Build Tool**: Vite
* **State Management**: Redux Toolkit
* **Routing**: React Router DOM
* **Testing**: Vitest, React Testing Library, User Event
* **Styling**: CSS Modules (SASS)

## 📂 Project Structure Highlights
* `src/components/` — Modular UI components (Notepad, Calculator, etc.).
* `src/store/` — Redux Toolkit slices and store configuration.
* `src/assets/` — Visual assets.
* `tests/` — Integration and unit tests.
